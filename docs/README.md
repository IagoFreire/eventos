## 🎯 Por Onde Começar?

1. 📖 Leia o [COMANDOS.md](COMANDOS.md) para comandos rápidos

3. 🏗️ Entenda a [arquitetura](ARCHITECTURE.md)
4. 💳 Configure o [Mercado Pago](MERCADOPAGO_INTEGRATION.md)

1. ⚙️ Siga o [CONFIGURACAO_PRODUCAO.md](CONFIGURACAO_PRODUCAO.md) completo

### Para Entender o Projeto
1. 📋 Veja o [resumo completo](PROJECT_SUMMARY.md)
2. 🏛️ Estude a [arquitetura](ARCHITECTURE.md)
3. 🎨 Veja as [atualizações visuais](ATUALIZACAO_VISUAL.md)

### Para Usar o Sistema
1. 📖 Leia o [README.md](../README.md) principal
2. 🔌 Teste no [modo offline](OFFLINE_MODE.md)
3. 🎫 Entenda o [sistema de ingressos](INGRESSO.md)
